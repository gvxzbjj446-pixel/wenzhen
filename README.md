# 王艳霞中医门诊 · 问诊记录系统

安装在诊所电脑上的中医门诊病历软件：患者建档、四诊问诊记录、开方打印、复诊提醒、理疗康复、方剂库、统计与备份。
像普通软件一样双击桌面图标打开，有独立窗口和菜单，**不需要浏览器、不需要联网**，数据只保存在本机。

## 功能一览

| 模块 | 说明 |
|---|---|
| **工作台** | 按姓名 / 电话 / 病历号搜索患者；今日接诊、本月接诊与收费；今日应复诊和逾期未复诊提醒 |
| **患者档案** | 基本信息、过敏史（醒目红色提示）、既往史、家族史；只知道年龄时可只填年龄；历次就诊时间线 |
| **问诊记录** | 按中医四诊组织：主诉、现病史、十问（寒热、汗、头身、胸腹、饮食、口渴、睡眠、二便、耳目、经带胎产），望闻切（舌质、舌苔、脉象）、辅助检查，中西医诊断、证型、治则治法，其他治疗、医嘱、收费、预约复诊 |
| **快速录入** | 各项症状、舌象、脉象均有常用描述，点击即填入、再点取消（脉象自动连写为“弦细数”） |
| **开方** | 药名联想；从方剂库一键引用（替换或合方）；整张方子粘贴识别（如 `黄芪30 当归10 砂仁6后下 7剂`）；自动统计味数与每剂总量；**十八反、十九畏及药物重复实时提示** |
| **复诊** | “以此复诊”带入上次主诉、诊断与处方，舌脉症状重新诊察；表单右侧同时显示上次就诊摘要 |
| **打印** | A5 处方笺（诊所名、患者信息、诊断、过敏史、Rp.、剂数用法、医师签名）；A4 门诊病历 |
| **方剂库** | 独立导航入口；按方名 / 出处 / 功用主治 / 药名搜索，按出处筛选；查看组成、用法与备注，复制为经验方，选患者或建档后带入问诊；处方编辑器支持搜索、预览与引用，既有处方可另存为经验方。保留原有 10 首示例方，不新增临床推荐 |
| **复诊提醒** | 列出即将复诊和逾期未来的患者及电话，患者再次就诊后提醒自动消失 |
| **理疗康复** | 针刺、电针、艾灸、拔罐、推拿、刮痧等理疗按**疗程**管理：诊断、治疗部位、康复目标、初次评估（疼痛评分 0–10）、治疗方案、计划次数与频次；**每次治疗**按上次内容预填，点选穴位即可填入，记录治疗前后疼痛评分、治疗反应与收费；疗程页显示进度和疼痛评分变化图；结束时填写疗效（痊愈 / 显效 / 有效 / 无效）与小结；可打印 A4 理疗治疗单（未做的次数留空行，可手写签字）；超过频次没来治疗的患者在工作台提醒；理疗项目（默认时长、参考价格）可自行维护 |
| **统计** | 按月接诊人次、患者数、初诊数、收费；常见诊断、证型、常用方、常用药物（含平均剂量）；就诊患者性别与年龄构成；理疗人次、收费、常用理疗项目、疗效分布与平均疼痛评分变化 |
| **数据备份** | 每天自动备份，历史备份长期保存（最近 30 天每天一份，更早的每月一份）；可自动同步到 U 盘或网盘文件夹；导出完整数据包（含 JSON 与 CSV）用于迁移到其他系统；可从任一备份恢复，恢复前自动保存当前数据 |

## 下载与安装

### Windows（推荐）

1. 到 [Releases 下载页](https://github.com/gvxzbjj446-pixel/wenzhen/releases/latest) 下载 **`WenzhenClinic-Setup-版本号.exe`**。
2. 双击运行安装程序 → 下一步 → 完成。不需要管理员权限，也不需要安装 Python。
3. 桌面和开始菜单会出现 **「王艳霞中医门诊」** 图标，双击即可打开。

- 适用于 Windows 10 / 11（64 位）。软件界面由系统自带的 Microsoft Edge WebView2 显示；个别电脑缺少时，安装程序会自动安装。
- 不方便安装时可用 **绿色版**：解压 `WenzhenClinic-Portable-版本号-Windows.zip`，双击其中的 `Wenzhen.exe`。
- 升级：直接运行新版安装程序覆盖安装，数据不受影响。

### macOS

在同一下载页下载 `WenzhenClinic-版本号-macOS.zip`，解压后把「王艳霞中医门诊」拖到“应用程序”。
（适用于 Apple 芯片的 Mac；软件未经苹果公证，首次打开请在访达中右键 → 打开。）

### 首次使用

打开软件后按提示创建医师账户，并填写诊所名称和医师姓名（会打印在处方上）。之后每次打开需登录。

完成设置时会同时建立**系统管理员**账户：用户名 `admin`，密码 `888888`。医师账户忘记密码时，
可以用它登录，在「设置 → 账户与密码」中管理账户。系统管理员账户不能删除；建议登录后修改初始密码。
从旧版本升级时，系统管理员账户会自动补上。

## 使用说明

- **菜单栏**：「文件」中有新患者建档、导出完整数据包…、从备份恢复…、数据备份与恢复、打开数据文件夹；「查看」可快速跳到工作台、患者、复诊提醒、理疗康复。
- **关闭窗口**：如果问诊表单还没保存，会先提醒，避免误关丢失内容。
- 软件已打开时再次双击图标，会直接切换到已打开的窗口。
- **打印**：在处方或病历的打印页点“打印”（或按 Ctrl+P），可选择打印机或另存为 PDF。
- **处方快速录入**：点“快速录入”，输入或粘贴整张方子，药名后直接跟剂量；单位可写 g/克/枚/片/个 等，
  脚注（先煎、后下、包煎、烊化、冲服……）直接写在剂量后面；写 `7剂` 会自动填入剂数。
- 在药物表格中按 **回车**：从药名跳到剂量，再跳到下一行（没有下一行会自动新增）。
- 从方剂库引用时选“加入此方药物”可合方，方名会自动写成“甲方合乙方”。
- 配伍禁忌提示只作提醒，不会阻止保存，是否同用由医师决定。
- 男性患者的问诊表单会隐藏“经带胎产”一栏。
- **理疗**：在患者档案点「＋ 理疗疗程」（或在某次病历中点「开理疗疗程」，自动带入诊断），填好方案后点「保存并记录第 1 次治疗」。
  之后患者每次来，在「理疗康复」页或患者档案中点「记录治疗」，项目和穴位已按上次填好，改动后保存即可。
  录入项目时，先点一下某一行，再点下方的穴位 / 部位，就会填入这一行；再点一次取消。计划次数做完后点「结束疗程」填写疗效与小结。

## 数据与备份

所有数据在一个文件里：Windows 为 `%APPDATA%\WenzhenClinic\wenzhen.sqlite3`，macOS 为 `~/Library/Application Support/WenzhenClinic/`。
卸载软件不会删除数据。备份的各项操作都在「设置 → 数据备份与恢复」（或菜单「文件 → 数据备份与恢复」）。

### 自动备份与历史保留

- 每天第一次使用时自动备份；关闭软件时再用当天的最新数据更新这份备份。
- **最近 30 天每天保留一份，更早的每个月保留最后一份，长期保存**，可以找回任何月份的历史数据。
- 手动备份和“恢复前自动保存”的备份不会自动删除。

### 备份到这台电脑以外（强烈建议）

电脑硬盘损坏或丢失时，只存在本机的备份会一起丢失。

- **外部备份文件夹**：选择 U 盘、移动硬盘，或百度网盘、坚果云等网盘的同步文件夹，之后每次备份都会自动复制一份过去；
  U 盘没插时漏掉的备份，下次连接后会自动补上。
- 或者用「导出完整数据包…」手动存到 U 盘。
- 外部备份周期提醒仅在设置和备份页显示；工作台保留实际备份失败告警。

### 备份包格式（迁移到其他系统）

备份文件是 `.zip` 包，用任何解压软件都能打开：

| 文件 | 内容 |
|---|---|
| `wenzhen.sqlite3` | 完整数据库（SQLite 3），在本软件中恢复时使用 |
| `manifest.json` | 备份时间、软件版本、各类记录数、每个文件的 SHA-256 校验值（恢复时自动核对） |
| `README.txt` | 中文说明：如何恢复、各文件和字段的含义 |
| `data.json` | 全部数据的结构化 JSON：患者 → 就诊记录 → 处方，患者 → 理疗疗程 → 每次治疗，附各字段中文含义（完整数据包才有） |
| `csv/*.csv` | 患者、就诊记录、处方明细、方剂、方剂组成、理疗疗程、疗程方案、治疗记录、治疗项目明细、理疗项目共十张表，中文列名，用 ID 相互关联，Excel 可直接打开（完整数据包才有） |

每日自动备份只含数据库和说明（体积小）；「立即备份」和「导出完整数据包」生成含 JSON 与 CSV 的完整数据包。

### 恢复与换电脑

- 在「数据备份与恢复」页面的列表中选择任一备份点“恢复”，或用「从备份文件恢复…」选择 U 盘、其他电脑上的备份（`.zip`，或 1.1 版的 `.sqlite3`）。
- 恢复前会核对文件是否完好，并把当前数据自动另存一份；恢复后需要重新登录。
- 换电脑：在新电脑安装本软件 → 「文件 → 从备份恢复…」。外部备份文件夹等本机设置不会被备份覆盖。

### 忘记密码

在命令提示符中运行（安装在默认位置时）：

```bat
"%LOCALAPPDATA%\Programs\WenzhenClinic\Wenzhen.exe" --reset-password 用户名 新密码
```

会弹窗提示“已重置”；用户名不存在时会新建该账户。

## 高级：让手机、平板也能访问

桌面版只允许本机使用。如需在诊所局域网内用手机、平板访问，可在装有 Python 3.9+ 的电脑上以服务器方式运行：

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt     # Windows: .venv\Scripts\pip install -r requirements.txt
.venv/bin/python run.py --lan
```

窗口会显示局域网地址（如 `http://192.168.1.20:5000`），同一 Wi-Fi 下的设备用浏览器打开即可。
服务器方式的数据在项目的 `instance/` 目录。**请不要把它直接暴露到公网。**

## 系统设计

```
桌面窗口（Windows：Edge WebView2 ／ macOS：WKWebView）
  │  菜单、另存为/打开对话框、关闭前提醒 ── wenzhen/desktop.py
  │  HTTP，仅本机 127.0.0.1 随机端口
  ▼
waitress 服务线程（同一进程内）
  │
  ▼
wenzhen/（Flask 应用）
  ├─ auth.py       登录、首次设置
  ├─ patients.py   患者档案
  ├─ visits.py     问诊记录、打印、就诊列表、复诊提醒
  ├─ formulas.py   方剂库
  ├─ therapy.py    理疗康复：疗程、每次治疗、疼痛评分变化图、治疗单、理疗项目
  ├─ therapy_data.py  预置理疗项目、穴位与部位快选、治疗反应、疗效等选项
  ├─ main.py       工作台、统计、设置、账户、导出与备份
  ├─ fields.py     问诊字段与常用描述（改这里即可增减问诊项目）
  ├─ herbs.py      药名联想词库、煎服法、预置方剂
  ├─ compat.py     十八反、十九畏规则
  ├─ desktop.py    桌面版外壳：窗口、菜单、本机对话框、单实例、自检
  └─ templates/ static/   页面与样式（无外部依赖，可离线使用）
        │
        ▼
数据目录/wenzhen.sqlite3（SQLite 单文件数据库）
```

数据表：

| 表 | 内容 |
|---|---|
| `patients` | 患者档案：姓名、性别、出生日期、电话、住址、职业、过敏史、既往史、家族史、备注 |
| `visits` | 门诊病历：每次就诊一条，含四诊、诊断、治法、方名、剂数、煎服法、医嘱、收费、预约复诊日期 |
| `prescription_items` | 处方明细：药名、剂量、单位、脚注，按顺序排列 |
| `formulas` / `formula_items` | 方剂库及其组成 |
| `therapy_types` | 理疗项目：名称、类别、默认时长、参考价格、操作要点，可停用 |
| `therapy_courses` / `therapy_course_items` | 理疗疗程（诊断、部位、目标、初评与末评疼痛评分、计划次数、频次、疗效、小结）及其治疗方案 |
| `therapy_sessions` / `therapy_session_items` | 每次治疗（日期、治疗前后疼痛评分、反应、记录、治疗者、收费）及其项目明细（项目、部位 / 穴位、时长、手法） |
| `users` | 登录账户（密码加盐哈希保存） |
| `settings` | 诊所名称、医师姓名、地址电话；新建问诊时的默认煎服法与剂数；备份相关的本机设置 |

**增加问诊项目**：在 `wenzhen/fields.py` 对应分组中加一个 `Field(...)` 即可，重启后系统会自动给已有数据库补上这一列；
表单、详情、打印和导出都会自动出现该项。（也请在 `wenzhen/schema.sql` 的 `visits` 表中补上同名列，便于查阅。）

## 开发与测试

```bash
python -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest          # 自动化测试
.venv/bin/python -m wenzhen         # 从源码启动桌面版
```

### 打包

```bash
pip install -r requirements-desktop.txt pyinstaller
pyinstaller --noconfirm --clean packaging/wenzhen.spec      # 生成 dist/Wenzhen/（macOS 为 .app）
iscc /DAppVersion=1.1.0 packaging/installer.iss             # Windows：生成安装程序（Inno Setup 6）
```

推送代码后，GitHub Actions（`.github/workflows/build.yml`）会自动：运行测试 → 在 Windows、macOS 上打包 →
打开窗口做自检 → 静默安装后再自检 → 上传安装包。

**发布新版本**：修改 `wenzhen/__init__.py` 中的版本号并提交，然后推送同名标签（如 `git tag v1.2.0 && git push origin v1.2.0`），
或在 GitHub 的 Actions 页面手动运行“测试与打包”并勾选“发布正式版本”（由 Actions 自动创建标签）。
Windows 安装包测试通过后自动发布到 Releases 页面（说明文字来自 `packaging/release-notes.md`），macOS 版构建完成后自动附上。
手动运行时还可以：在“要打包的提交或标签”中填写某个历史提交，补发旧版本（不会顶替更新的版本成为“最新版本”）；
在“要删除的旧版本标签”中填写如 `v1.1.0`，把该版本的发布页和标签一并删除（同时发布新版本时，新版本发布成功后才删除）。
版本号在 `wenzhen/__init__.py` 中修改；图标由 `packaging/make_icon.py` 生成。
